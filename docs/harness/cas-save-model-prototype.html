    情况Repository 行为可观察结果
    首次保存直接 INSERT，lock_version = 0主键/唯一键竞争只有一个成功
    已有聚合保存使用加载时版本执行单条 CAS UPDATE恰好更新一行才成功
    陈旧版本根行 UPDATE 返回零行，立即停止抛持久化冲突，子记录不变
    同一上下文再次保存以上一次 RETURNING 的新版本继续 CAS每次实际 flush 递增一次
    未在当前事务加载不得猜测最新版本或执行无条件 UPDATE按新建 INSERT；重复 ID 转持久化冲突
     
    UPDATE executions
SET state = :state,
    generation = :generation,
    lock_version = lock_version + 1
WHERE company_id = :company_id
  AND id = :id
  AND lock_version = :expected_lock_version
RETURNING lock_version;
