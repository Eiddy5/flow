# UC 测试报告

本目录保存 Test Agent 根据 `docs/uc/` 中的 UC Markdown 文档执行测试后
生成的历史报告。

## 目录结构

测试报告按照 UC 领域归档：

```text
docs/test-reports/
  flow/
    UC-01-2026-07-27-1530.md
  external-task/
    UC-04-2026-07-27-1600.md
```

领域目录必须与目标 UC 的 UC 领域归属一致。不能使用 `misc`、`other` 或
`common` 等模糊目录。

## 文件命名

报告文件名使用：

```text
<UC-ID>-<YYYY-MM-DD-HHmm>.md
```

同一个 UC 每次执行都生成新报告，不覆盖或删除历史报告。复验报告必须引用上一次
报告及相关反例。

## 内容要求

每份报告至少包含：

- UC 文档和唯一测试类路径。
- 测试时间、类型、环境和代码版本。
- 全部场景的测试方法映射。
- 全部 `PASS-*` 的状态和证据。
- 执行命令与结果。
- PASS、FAIL、NOT_COVERED、BLOCKED 数量。
- 失败、反例、构建产物和未解决事项。

报告是测试执行事实，不是开发规范或 UC 定义。不得在报告中修改业务预期，也不得
记录密码、令牌、完整环境变量或其他秘密。
