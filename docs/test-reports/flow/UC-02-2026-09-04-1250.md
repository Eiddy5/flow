## 验证范围

全部 10 个场景均通过公开 Service 运行，没有直接调用 Repository 或用数据库查询
替代用户行为断言。版本预期使用独立字面量：首次草稿 v1、首次发布 v2、修改草稿
v3、再次发布 v4；运行实例始终绑定启动时选定的正式版本。

新增 S10 在同一租户和 key 下先准备内容可区分的正式 v2 与当前正式 v4，分别通过
公开 Flow 查询确认两版可用，然后直接调用公开 `ExecutionService.create` 并传入
`Optional.of(2L)`。测试在中间态查询到 PAUSED，提交 v2 Pause 结果后再次通过公开
Execution 查询，核对步骤 ID 列表与 v2 定义完全相同、与 v4 步骤 ID 无交集，并确认
最终输出、版本及活动步骤。
