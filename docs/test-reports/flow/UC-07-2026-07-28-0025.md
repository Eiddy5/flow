## 测试范围

通过公开 `FlowService` 使用 YAML 保存并发布两层嵌套 Flow，通过
`ExecutionService` 启动和取消，通过 `ExternalTaskService` 完成三个深层
PAUSE。覆盖递归定义身份、直接父子拓扑、并行孙 Task、深层恢复、依赖汇合、
跨层重复 key、深层取消、恢复顺序变异和层级上移变异。

## 测试结论

UC-07 整体通过。当前实现能够在单 Execution 内递归展开两层 Task，在两个深层
PAUSE 分支、依赖汇合、第二个深层等待点和后续顶层 Task 之间形成唯一且一致的
执行历史；取消、重复 key 和两种变异场景也符合规范。
