Execution；没有通过 Repository 或 Executor 捏造 UC 结果。重点验证未命中 Route TaskRun

拒绝 SKIPPED；SKIPPED TaskRun 不能作为 rewind 目标；Executor 对未命中 Route 不创建子
TaskRun；SKIPPED 状态及三段历史可通过 PostgreSQL JSONB 保存和恢复。
