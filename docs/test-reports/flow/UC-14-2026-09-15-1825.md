## 失败与反例

首次真实链路验证暴露并由主 Agent 修复了以下问题，随后同一 UC 场景已通过，未降低断言：

1. Micronaut DataSource 事务代理不能由调度内核直接 getConnection，启动时 `NoConnectionException`；使用底层连接池接入调度器。
2. 仅注册 recurring handler 未创建 outbox 首次任务，导致 FLOW_CHANGED 一直未投递；显式注册启动任务后推进。
3. PAAS 省略空 inputs，事件回读 `Map.copyOf(null)` 抛 `ValueInstantiationException`；按空输入协议恢复，另补两类事件空 Map 往返测试。
4. 普通 DSLContext 无 Entry/JsonObjects 映射配置，配置消费者 `MappingException`；复用具名 JOOQ 配置。

本次还修复了构建资源任务自环；测试夹具按 Core 现有配置排除不属于验收的宿主 Temporal/诊断能力。以上均不改变 UC 预期。
