# UC-08 用户在流程中输出动态日志

## 验证标识

- UC：`UC-08`
- 状态：`ACCEPTED`
- 领域：`flow`
- UC 类型：`任务类型`
- 目标任务类型：`日志`
- 需求基线：`用户确认的日志扩展需求@2026-08-04`
- 依赖：`UC-01`、`UC-02`

## 验证目标

验证用户能够在流程中配置一条包含动态值的日志消息，运行时从前置结果提取实际值
并输出日志；无效表达式或缺少运行值不会产生误导日志或错误推进后续步骤。

## 验证场景

### S1 输出包含前置结果的日志并继续流程

- 参与用户：流程编排用户、流程发起用户、日志查看用户
- 开始状态：用户可以定义并发布包含日志步骤的标准验证流程
- 验证流程：开始后由前置步骤产生一个确定结果，进入唯一目标日志任务输出包含该结果的消息，再由后置观察步骤继续并结束
- 用户操作：编排用户配置包含固定文本和前置结果表达式的日志消息并发布流程；发起用户启动独立流程实例；日志查看用户查询本次运行产生的应用日志；三名用户重新查询流程结果
- 预期结果：目标日志任务只执行一次，日志中固定文本保持不变且表达式被替换为前置步骤的实际结果，不出现未解析表达式；后置步骤继续执行
- 场景结束：流程已完成，没有活动步骤

### S2 发布包含无效消息表达式的流程

- 参与用户：流程编排用户
- 开始状态：用户可以定义包含唯一目标日志任务的流程草稿
- 验证流程：开始后由前置步骤准备输入，进入唯一目标日志任务，成功时再由后置观察步骤继续并结束
- 用户操作：用户定义包含无效消息表达式的流程并尝试发布，收到拒绝后尝试启动该流程，再重新查询可运行版本并删除无效草稿
- 预期结果：发布被明确拒绝，目标日志任务没有进入运行，没有产生包含无效表达式的可运行流程版本，也没有输出日志或启动流程实例
- 场景结束：无效草稿已删除，没有遗留可运行版本或运行实例

### S3 日志表达式引用不存在的运行值

- 参与用户：流程编排用户、流程发起用户、日志查看用户
- 开始状态：用户可以定义并发布表达式语法有效但运行时路径不存在的标准验证流程
- 验证流程：开始后由前置步骤产生不包含目标路径的结果，进入唯一目标日志任务，成功时才由后置观察步骤继续并结束
- 用户操作：编排用户定义并发布流程；发起用户启动独立流程实例并重新查询最终状态与步骤结果；日志查看用户查询本次运行日志
- 预期结果：目标日志任务明确失败，不输出未解析表达式或空值日志，后置步骤不执行，流程显示失败
- 场景结束：流程已失败，没有活动步骤

## 验证方式

### S1

1. 编排用户定义并发布包含唯一目标日志步骤的标准验证流程，消息同时包含固定文本和前置结果表达式。
2. 发起用户启动独立流程实例并查询运行结果，日志查看用户按消息内容查询应用日志。
3. 三名用户确认目标日志任务和后置步骤各执行一次，日志包含解析后的实际值且没有未解析表达式。
4. 发起用户确认流程已完成且没有活动步骤。

### S2

1. 编排用户定义包含唯一目标日志任务和无效消息表达式的流程草稿并尝试发布。
2. 用户确认发布被拒绝，尝试启动后再次查询并确认没有生成新的可运行版本。
3. 用户确认目标日志任务没有运行，也没有日志和运行实例副作用。
4. 用户删除无效草稿并确认清理完成。

### S3

1. 编排用户定义并发布表达式语法有效但目标运行值不存在的标准验证流程。
2. 发起用户启动独立流程实例并查询最终状态和步骤历史。
3. 日志查看用户确认没有输出未解析表达式或空值日志，发起用户确认后置步骤没有执行。
4. 发起用户确认流程已失败且没有活动步骤。
