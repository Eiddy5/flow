# Flow UC 领域

## 领域边界

本目录保存用户管理 Flow 草稿、启动和取消流程、运行自动流程、处理外派任务、处理
并行任务、选择条件路径以及完成多阶段长流程的 UC。

## UC 格式

所有 UC 已迁移到 `$generate-uc` 四章节格式，只描述真实用户场景：

- 每个 UC 明确标识为流程编排、流程运行或任务类型。
- 用户从可见业务状态开始。
- 用户通过查询识别要操作的草稿、流程或任务。
- 用户执行真实操作并重新查询结果。
- 每个场景独立完成、取消、失败、明确未创建或完成资源清理。

任务类型 UC 必须在每个场景定义并发布标准验证流程，启动独立流程实例，观察目标
任务结果并证明结果被后续步骤消费。流程等待外派处理时，被外派用户必须从自己的
待办中查询具体任务，完成查询所得任务，再查询后续待办和流程结果。不能把等待
状态作为正常场景的结束。

## 推荐验证顺序

```text
UC-01 -> UC-02 -> UC-03 -> UC-04 -> UC-06 -> UC-05 -> UC-07
```

UC-01 建立流程定义基础；UC-02 验证启动和推进；UC-03、UC-04 分别验证 AUTO 和
PAUSE 任务；UC-06、UC-05 分别验证条件和并行编排；UC-07 综合验证多阶段编排。
