# UC-03 用户运行自动流程

## 验证标识

- UC：`UC-03`
- 状态：`ACCEPTED`
- 领域：`flow`
- UC 类型：`任务类型`
- 目标任务类型：`自动执行任务`
- 需求基线：`用户确认的 Flow 完整用户路径规则@2026-07-28；流程启动请求提交后即可返回@2026-08-12`
- 依赖：`UC-01`、`UC-02`

## 验证目标

验证用户在完整流程中使用自动任务时，目标任务能够自动执行一次并把结果交给后续
步骤；明确失败或意外异常不会造成跳步、重复执行、部分结果或遗留运行资源。

## 验证场景

### S1 目标自动任务成功并传递结果

- 参与用户：流程发起用户
- 开始状态：用户可以定义并发布包含目标自动任务的标准验证流程
- 验证流程：开始后由前置步骤准备输入，进入唯一目标自动任务，成功后由后置观察步骤读取输出并结束
- 用户操作：用户定义并发布验证流程，启动独立流程实例，再查询最终结果和完整步骤历史
- 预期结果：目标自动任务使用前置输入执行一次并完成，后置观察步骤取得目标任务输出且只执行一次
- 场景结束：流程已完成，没有活动步骤

### S2 目标自动任务明确失败

- 参与用户：流程发起用户
- 开始状态：用户可以定义目标自动任务会返回明确失败结果的标准验证流程
- 验证流程：开始后由前置步骤准备输入，进入唯一目标自动任务，成功时才由后置观察步骤读取输出并结束
- 用户操作：用户定义并发布验证流程，启动独立流程实例，再查询最终状态、已执行步骤和未执行步骤
- 预期结果：前置步骤完成，目标自动任务执行一次并明确失败，后置观察步骤不执行，流程显示失败
- 场景结束：流程已失败，没有活动步骤

### S3 目标自动任务发生意外异常

- 参与用户：流程发起用户
- 开始状态：用户可以定义目标自动任务会发生意外异常的标准验证流程
- 验证流程：开始后由前置步骤准备输入，进入唯一目标自动任务，成功时才由后置观察步骤读取输出并结束
- 用户操作：用户定义并发布验证流程，启动独立流程实例取得运行编号，再查询最终状态和步骤历史
- 预期结果：启动请求被异步受理；前置步骤完成，目标自动任务执行一次并记录意外异常，后置步骤不执行，流程显示失败
- 场景结束：流程已失败，没有活动步骤

## 验证方式

### S1

1. 用户定义并发布包含唯一目标自动任务的标准验证流程。
2. 用户启动独立流程实例并查询运行结果。
3. 用户查询前置输入、目标任务输出和后置观察结果，确认目标任务及后置步骤各执行一次。
4. 用户确认流程已完成且没有活动步骤。

### S2

1. 用户定义并发布目标自动任务会明确失败的标准验证流程。
2. 用户启动独立流程实例并查询最终状态。
3. 用户查询步骤历史，确认前置步骤完成、目标任务失败且后置观察步骤未执行。
4. 用户确认流程已失败且没有活动步骤。

### S3

1. 用户定义并发布目标自动任务会发生意外异常的标准验证流程。
2. 用户启动独立流程实例并取得运行编号。
3. 用户按运行编号重新查询最终状态和步骤历史。
4. 用户确认目标任务失败、后置步骤没有执行且没有活动步骤。
