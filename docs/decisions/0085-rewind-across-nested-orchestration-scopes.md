# ADR 0085：跨嵌套编排作用域退回

## 状态

Accepted（2026-09-07），依据本次用户确认。扩展 ADR 0078 的顶层串行限制；继续遵循 ADR 0082、0084 的宿主整存后投递命令及快照冲突检测。

## 决策

- 按定义树的串行先后及并行分支关系判断前驱，不用 TaskRun 追加顺序判断并行节点先后。源是有效 PAUSED Pause，目标是有效已完成前驱；同级并行分支不能互退。
- 允许同分支、分支向外、汇合向实际经过的分支及多层嵌套退回。循环内部的端点仍不在本次范围内；完整循环作为中间片段可随前驱重跑。
- `RewindPath` 计算目标及其因果后继中已经存在的有效 TaskRun，按逆序返回给宿主；无因果依赖的并行兄弟不失效。
- Generation Current 和 History 在现有 JSONB 中持久化 `affectedTaskRunIds`。旧记录没有此字段时按原顶层区间恢复。已失效的运行实例始终不再进入 effectiveTaskRuns，即使新一轮尚未生成其替代实例。
- 受影响的未完成 TaskRun 终止，重审生成新 TaskRun 与执行 Generation。只部分受影响的祖先编排容器沿用原 ID，追加 RUNNING 状态历史并清除旧 outputs，让未受影响的子实例保留父身份。普通 Task 与 Pause 不通过此入口重开。
- 调度从有效 occurrence 读取，重放 occurrence 取导致其失效的 Generation；父容器重建时子实例使用新父 ID。恢复原源节点后归档当前 Generation，历史仍保留精确失效集合。
- 宿主通过只读 `previousCompletedTaskRuns` 提供候选 Task keys，从实际有效路径取得最近已完成前驱；条件组的其他分支不作为组内节点的前驱。哪些 Task 表示审批、能否退回及当前用户权限仍由 CSES 决定。

## 验证

沿用 UC-04；UC-10 S7–S13 用真实 PostgreSQL 和公开服务入口验证退回、重复退回、无关并行待办保留、旧实例拒绝和后续完成。客户端另外覆盖配置与后端返回的有效候选，不从历史时间排序推断可退回路径。
