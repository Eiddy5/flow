# UC-09 用户处理外派任务

## 验证标识

- UC：`UC-09`
- 状态：`ACCEPTED`
- 领域：`flow`
- UC 类型：`任务类型`
- 目标任务类型：`PAUSE`
- 需求基线：`用户确认的外派任务需求@2026-07-29`
- 依赖：`UC-02`

## 验证目标

验证用户能够查询并完成自己的外派任务，使对应流程使用提交结果继续运行。

## 验证场景

### S1 用户完成自己的外派任务

- 参与用户：流程发起用户、外派任务处理用户
- 开始状态：用户可以定义和发布包含外派任务的流程
- 验证流程：开始后由前置步骤准备输入，进入唯一目标外派任务，完成后由后置步骤读取结果并结束
- 用户操作：流程发起用户定义并发布验证流程、启动流程；任务处理用户查询并完成自己的具体任务；两名用户重新查询任务和流程
- 预期结果：目标任务完成，只有对应流程继续运行，后置步骤取得用户提交的结果
- 场景结束：流程完成且不遗留等待任务

### S2 其他租户完成外派任务

- 参与用户：流程发起用户、其他租户用户、有权任务处理用户
- 开始状态：目标流程正在等待有权用户处理外派任务
- 验证流程：开始后由前置步骤准备输入，进入唯一目标外派任务，完成后由后置步骤读取结果并结束
- 用户操作：其他租户用户查询并尝试完成目标任务；流程发起用户重新查询流程；有权用户查询并完成自己的任务
- 预期结果：其他租户不能查询或完成目标任务，目标流程没有被错误推进；有权用户完成后对应流程继续运行
- 场景结束：流程完成且不遗留等待任务

## 验证方式

### S1

1. 流程发起用户定义并发布标准验证流程，然后启动独立流程实例。
2. 任务处理用户从自己的待办中查询并识别目标任务，提交合法结果。
3. 两名用户重新查询，确认目标任务完成、对应流程继续且后置步骤取得提交结果。
4. 流程发起用户查询流程完成，并确认没有遗留等待任务。

### S2

1. 流程发起用户定义并发布标准验证流程，然后启动独立流程实例。
2. 其他租户用户查询并尝试完成目标任务，确认无法查询或操作。
3. 流程发起用户重新查询，确认流程没有被错误推进。
4. 有权用户重新查询并完成目标任务，流程发起用户确认流程完成且没有遗留等待任务。
