# 流程编排 UC 覆盖参考

## 验证对象

验证用户定义、修改、发布和观察流程结构时的业务结果。具体 Task 只作为可观察的
确定性步骤，不是验证目标。

## 候选维度

根据已确认需求审计：

- 单步骤、顺序步骤和步骤顺序变化。
- 条件分支、无匹配分支和多匹配规则。
- 并行、汇聚、不同完成顺序和禁止提前汇聚。
- 嵌套、多阶段、层级调整和深层结束。
- 空流程、断路、不可达步骤、循环和错误引用。
- 重复步骤标识、非法条件及其他无效定义。
- 草稿创建、查询、修改、发布、删除和发布失败恢复。
- 多用户协作及多租户定义隔离。

## 归属规则

- 版本发布属于编排或定义生命周期；运行实例选择版本属于流程运行。
- 并行或分支中使用某种 Task，不代表场景属于任务类型 UC。
- 只有具体 Task 的结果或交互规则改变时，才把该行为归入任务类型 UC。
- 不为同一编排规则按每种 Task 类型复制场景。
