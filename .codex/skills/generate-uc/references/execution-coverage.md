# 流程运行 UC 覆盖参考

## 验证对象

验证用户如何启动、查询、推进和结束已经发布的流程。使用最小且结果确定的流程，
不重复验证编排结构或具体 Task 的特殊行为。

## 候选维度

根据已确认需求审计：

- 正常启动、查询、完成和取消。
- 同一流程的多个运行实例及输入、输出和状态隔离。
- 相同或不同用户并发启动，以及重复或幂等启动。
- 默认版本、指定版本、不可用版本和新旧版本并存。
- 发布新版本时已经运行的实例保持原有版本。
- 运行失败、取消、恢复、重试和终态后的重复操作。
- 完成与取消、恢复与取消等竞争结果。
- 用户离开或服务重启后通过公开查询继续处理。
- 不存在、不可用或不可见流程的启动拒绝。
- 多用户权限和多租户运行隔离。

## 归属规则

- 流程内容是否合法属于流程编排 UC。
- 某种 Task 如何成功、失败、暂停、回调或产生输出属于任务类型 UC。
- 只在版本或多实例改变运行实例结果时保留场景，不复制具体 Task 的场景矩阵。
