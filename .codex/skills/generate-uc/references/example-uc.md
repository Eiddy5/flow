# UC-08 用户取消运行流程

## 验证标识

- UC：`UC-08`
- 状态：`ACCEPTED`
- 领域：`flow`
- UC 类型：`流程运行`
- 需求基线：`docs/prd/execution.md@v1.2-confirmed`
- 依赖：`UC-02`

## 验证目标

验证用户能够取消自己正在运行的流程，并且不会影响其他流程。

## 验证场景

### S1 用户取消自己的运行流程

- 参与用户：流程发起用户
- 开始状态：目标流程和对照流程都在运行
- 用户操作：用户查询并识别目标流程，取消目标流程，再查询两个流程
- 预期结果：目标流程已取消，对照流程不受影响
- 场景结束：目标流程保持取消；对照流程由用户完成或取消

### S2 用户重复取消

- 参与用户：流程发起用户
- 开始状态：目标流程已经取消
- 用户操作：用户再次取消同一流程，并重新查询
- 预期结果：操作被明确拒绝，原状态和运行历史不变
- 场景结束：目标流程仍处于取消终态

## 验证方式

### S1

1. 用户分别启动目标流程和对照流程。
2. 用户从流程查询结果中识别目标流程并取消。
3. 用户重新查询两个流程，确认目标已取消、对照流程未改变。
4. 用户完成或取消对照流程，确认没有遗留运行资源。

### S2

1. 用户准备一个已经取消的流程。
2. 用户再次发起取消。
3. 用户重新查询流程状态和历史，确认请求被拒绝且没有变化。
